# skills

Agent skills by mikeleg, installable via [skills.sh](https://skills.sh).

## Install

```bash
npx skills add mikeleg/skills
```

## Structure

Each skill lives in its own folder with a `SKILL.md`:

```
skills/
  <skill-name>/
    SKILL.md
```

## Install as a Claude Code plugin

```
/plugin install mikeleg-skills --marketplace mikeleg/skills
```
